# HackHub Frontend

A modern, high-performance React + Vite hackathon platform interface featuring dynamic 3D visual animations, glassmorphism UI, AI mentor integrations, real-time team matching, project evaluation, and user profile customization.

## 🚀 Features

- **⚡ Fast & Modern Architecture**: Built with Vite, React 18, React Router v6, and TailwindCSS.
- **🎨 Glassmorphic & 3D UI**: Rich dark theme with 3D crystal animations (Three.js / React Three Fiber), magnetic buttons, and custom spotlight highlights.
- **🤖 AI Integration**: Interactive AI Mentor assistance, automated idea validation, project evaluation, and plagiarism analysis UI.
- **👥 Team & Profile Customization**: Comprehensive profile management with avatar customization, badges, banner choices, theme preferences, and team matching.
- **🏆 Hall of Fame & Competition Insights**: Interactive hackathon leaderboard and live analytical insights.

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Custom CSS Variables & Glassmorphism
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router DOM v6

## 📦 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
